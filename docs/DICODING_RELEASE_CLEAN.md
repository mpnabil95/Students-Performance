# Dicoding Submission — v1.0.0

Rilis ini mengarsipkan baseline proyek **Students Performance** untuk submission akhir kelas **Penerapan Data Science — Dicoding**, studi kasus **Menyelesaikan Permasalahan Institusi Pendidikan**.

Studi kasus Jaya Jaya Institut (fiktif) mencakup analisis faktor terkait status studi, klasifikasi Dropout/Enrolled/Graduate, prototype Streamlit, dashboard Metabase, serta rekomendasi pendampingan.

## Isi arsip

- Notebook analisis dan pemodelan dengan output.
- Aplikasi Streamlit, model XGBoost, dan label encoder.
- Dataset mentah serta hasil ekspor.
- Database Metabase, SQLite pendukung, dan screenshot dashboard.
- Requirements serta README penggunaan.
